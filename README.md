A token launch radar: it ranks pre-token protocols by an implied token value derived from the snapshot's own figures — TVL (with sublinear scaling, so the market pays less for each extra dollar of TVL), seven-day growth, how long the protocol has run with no token, and how many chains it runs on — and shows a concrete farm plan for each one. Protocols whose token already trades are set aside with their market caps, never ranked as launch candidates.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
